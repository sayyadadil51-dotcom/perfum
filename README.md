# Adersh Footwear — Online Store

A premium, mobile-first boutique store for **Adersh Footwear**, a leather house in Bandra, Mumbai.

- **Shop:** 9 signature silhouettes — sneakers, sport, oxfords, loafers, chelsea & desert boots, heels
- **Cart & checkout:** size picker, quantities, free shipping over ₹2,999, cash-on-delivery form
- **Sections:** editorial hero, new drop, collections, full catalogue with filters & search, house story, reviews, flagship, newsletter
- **Tech:** pure HTML + CSS + JS — no build step, no dependencies. Cart saved in `localStorage`.

## Run locally

```bash
python3 -m http.server 8000 --bind 0.0.0.0
# open http://localhost:8000
```

## Deploy on Vercel (free)

1. Push this branch / merge to `main`.
2. Import **sayyadadil51-dotcom/perfum** at [vercel.com/new](https://vercel.com/new).
3. Leave build settings empty — it is a static site.
4. Deploy. Optional: add a custom domain in **Settings → Domains**.
